# 保留券・手入力管理アプリ

パチンコ店の保留券・手入力処理を、レシート画像と一緒に記録する店舗向けWebアプリです。

## 主な機能

- レシート画像の撮影・アップロード
- 保留券／手入力の区分選択
- 4円・1円・0.5円パチンコ、20円・10円・5円・2円スロットのレート選択
- 日付、担当者、玉数・枚数、用途の記録
- 月ごとの記録台帳
- 担当者・用途の検索
- 確認待ち／確認済みの絞り込み
- 店舗責任者名と手書き確認サインの保存

## データについて

このリポジトリには、店舗で登録した台帳データ、レシート画像、確認サインは含まれていません。アプリのソースコードだけを公開しています。

## 技術構成

- Next.js / Vinext
- React / TypeScript
- Cloudflare D1
- Cloudflare R2
- Drizzle ORM

## ローカル起動

Node.js 22.13以降とpnpmを使用します。

```bash
pnpm install
pnpm dev
```

ブラウザで `http://localhost:5173` を開きます。

## ビルド

```bash
pnpm build
```
